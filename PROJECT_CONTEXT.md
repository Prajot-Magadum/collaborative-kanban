Project: Realtime Kanban (Full Stack)

Tech Stack:
- Frontend: Next.js 16, Tailwind v4, Socket.IO client
- Backend: Node.js, Express, Prisma ORM
- Database: PostgreSQL
- Auth: JWT
- Realtime: Socket.IO

Features already built:
- User signup/login
- JWT authentication
- Boards creation
- Lists creation
- Cards creation
- Drag and drop cards
- Move cards between lists
- Delete cards
- Delete lists
- Rename lists
- Realtime updates across tabs
- Secure sockets with JWT
- Trello-style UI with Tailwind
